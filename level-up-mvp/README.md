# LEVEL UP — Telegram Mini App MVP

Ранний демонстрационный MVP: главная панель, ежедневные миссии, XP/уровень, прогресс, профиль и редактирование цели. Сейчас состояние хранится в localStorage браузера. Это позволяет показать UX, но не является production-хранилищем и не синхронизируется между устройствами.

## 1. Что понадобится

- Node.js 20.9 или новее
- npm
- Telegram и @BotFather для публикации Mini App
- (следующий этап) Supabase для постоянного хранения данных

## 2. Запуск локально

```bash
npm install
npm run dev
```

Откройте http://localhost:3000.

## 3. Проверка production-сборки

```bash
npm run build
npm start
```

## 4. Подключение Telegram

1. Создайте бота через https://t.me/BotFather командой `/newbot`.
2. Скопируйте токен в `.env.local` (создайте файл на основе `.env.example`).
3. Не публикуйте токен и не добавляйте `.env.local` в Git.
4. Разместите приложение на HTTPS-хостинге.
5. В BotFather настройте Main Mini App / Menu Button и укажите HTTPS URL.
6. Endpoint `POST /api/telegram/validate` принимает `{ "initData": "..." }`, проверяет подпись HMAC и срок `auth_date`.
7. Клиентский экран пока демонстрационный: для production нужно вызывать endpoint, создавать серверную сессию и получать профиль из базы. Никогда не доверяйте `initDataUnsafe` как доказательству личности.

## 5. База данных

Файл `database/schema.sql` содержит базовую схему PostgreSQL. Выполните его в Supabase SQL Editor. RLS включён, но пользовательские политики намеренно не открыты: сначала необходимо реализовать доверенную серверную авторизацию и маппинг Telegram ID на профиль. Не отключайте RLS и не кладите service-role key в браузер.

## 6. Что входит / не входит

Входит:
- адаптивный тёмный интерфейс;
- три вкладки;
- демо-миссии;
- отметка выполнения и начисление XP;
- прогресс уровня;
- редактирование главной цели;
- Telegram WebApp SDK bootstrap;
- пример серверной проверки Telegram initData;
- схема базы данных.

Пока НЕ реализовано:
- AI-генерация персональных планов;
- регистрация и серверные сессии;
- постоянная синхронизация с Supabase;
- Telegram-бот и уведомления;
- Telegram Stars invoices, обработка pre_checkout_query / successful_payment, возвраты;
- административная панель;
- аналитика и реферальная система.

## 7. Платёжная безопасность

Для продажи цифровой подписки внутри Telegram используйте Telegram Stars (XTR) и актуальный Bot API. Не активируйте доступ при создании инвойса — только после проверенного `successful_payment`. Сохраняйте `telegram_payment_charge_id`, делайте обработчик идемпотентным, реализуйте `/paysupport`, условия и возвраты. Перед коммерческим запуском проверьте актуальные правила Telegram и применимые законы о защите потребителей и персональных данных.

## 8. Рекомендуемый следующий этап

1. Подключить серверную авторизацию Telegram.
2. Подключить Supabase и пользовательские RLS policies.
3. Перенести миссии, XP и цели из localStorage в PostgreSQL.
4. Добавить onboarding-диагностику и план на 7 дней.
5. Подключить AI через серверный API с лимитами и модерацией.
6. Реализовать Telegram Stars.
7. Провести закрытый тест на 20–30 пользователях.

## 9. Продуктовые принципы

- Не превращать пропуск дня в наказание.
- Не обещать медицинских, психологических или финансовых результатов.
- XP начислять за завершённые действия, а не за бесконечное использование приложения.
- Давать посильные задания и возможность адаптировать сложность.
- Пользователь должен иметь возможность удалить свои данные.
